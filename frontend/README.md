# Frontend

Minimal, domain-agnostic Single-Page Application (SPA) starting skeleton.

## Architectural & Technology Note

**The RFP does not mandate any technology or architecture for this part of the system, so both choices must be justified by the team.**

## Requirements

- **Node.js:** `v22.x` (LTS)
- **Package Manager:** `npm` `v10.x` (bundled with Node.js 22)

## Installation

From the repository root, navigate to the `frontend` directory and install the dependencies:

```bash
cd frontend
npm install
```
